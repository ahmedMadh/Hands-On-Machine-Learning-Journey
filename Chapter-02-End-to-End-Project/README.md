# California Housing Prices Prediction 🏠

An end-to-end Machine Learning project based on Chapter 2 of *"Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow"*. This project simulates a real-world data science assignment where the goal is to predict the median housing price in any California district using 1990 census data.

---

## 📌 Project Overview
The business objective is to build a regression model that estimates the median housing price for various districts (block groups) in California. The predictions generated by this model will be fed into a downstream Machine Learning pipeline to determine whether it is worth investing in a given area.

### Problem Framing:
* **Supervised Learning:** The dataset includes labels (the actual median housing prices).
* **Multiple Regression:** The model utilizes multiple features (population, median income, ocean proximity, etc.) to make predictions.
* **Univariate Regression:** The system predicts a single value per district.
* **Batch Learning:** The dataset is static and small enough to fit into memory.

---

## 🛠️ Data Science Pipeline (The Checklist)

Following a structured machine learning workflow, this project covers:

### 1. The Big Picture & Frame the Problem
* Understood the business objective and downstream usage of the model output.
* Analyzed the current manual estimation baseline (which has an error rate of >20%).

### 2. Get the Data
* **Dataset Used:** California Housing Prices from the StatLib repository (based on the 1990 California census).
* Automated data fetching and loading scripts using `pandas`.

### 3. Discover and Visualize the Data
* Explored geographical data using scatter plots (visualizing latitude/longitude vs. population density and prices).
* Analyzed correlations between features using the standard correlation coefficient (Pearson's $r$).
* Investigated attribute combinations (e.g., `rooms_per_household`, `population_per_household`).

### 4. Prepare the Data for ML Algorithms
* **Handling Missing Values:** Implemented strategies for missing numerical data (imputation).
* **Handling Categorical Attributes:** Processed text attributes (like `ocean_proximity`) using One-Hot Encoding.
* **Feature Scaling:** Applied standard scaling techniques to normalize numerical ranges.
* **Pipelines:** Created a clean, reusable `Scikit-Learn` pipeline for automated data preprocessing.

### 5. Select, Train, and Fine-Tune Models
* Explored and compared multiple baseline models:
  * Linear Regression
  * Decision Tree Regressor
  * Random Forest Regressor
* **Performance Measure:** Evaluated models using Root Mean Squared Error (RMSE).
* **Fine-Tuning:** Optimized hyperparameters utilizing `GridSearchCV` and `Cross-Validation`.
